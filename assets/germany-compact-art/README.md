# Delhi-Berlin Compact Event Art

Seven distinct event images generated for the India-Germany compact expansion. The full-resolution source PNGs are retained in `source/`; game-ready derivatives are 400x116, 24-bit BMP files in `mod/gfx/events_pics/`.

| Event picture key | Intended chapters |
| --- | --- |
| `aubm_ger_compact_signing` | Opening conference, Berlin's reply, equal compact ratification |
| `aubm_ger_machines_for_ore` | Industrial mission, armaments credit, machine-tool and resource bargains |
| `aubm_ger_monsoon_armour` | Indian armoured doctrine, staff exercises, adapting German methods |
| `aubm_ger_three_capitals` | Delhi-Berlin-Tokyo consultation, sphere disputes, Tripartite questions |
| `aubm_ger_caucasus_lifeline` | Persian corridor, Baku/Astrakhan logistics, rescuing the German front |
| `aubm_ger_suez_road` | British-war choice, Suez campaign, western Indian Ocean operations |
| `aubm_ger_independent_command` | Separate command, refusal of a German veto, Indian continuation after Berlin's collapse |

## Art direction

- Colorized 1930s/early-1940s documentary realism with subtle film grain.
- India is the principal actor; German or Japanese personnel appear only as advisers or liaison officers.
- Important faces, maps and vehicles remain inside the narrow central crop.
- No readable text, flags, party symbols, swastikas, logos or watermarks.
- Built-in image generation was used; final assets were center-cropped with high-quality bicubic scaling.

## Verification

All seven BMP files were checked as 400x116 and 24-bit. `contact-sheet.png` previews the exact game-ready crops at native size.
