# Additional Leader Portrait Sources

defensible redistribution licence. The build script converts those sources to
Darkest Hour's 36x50, 8-bit indexed BMP format. Officers whose source clearance
is unresolved use Darkest Hour Full's built-in `unknownleader` picture token.
