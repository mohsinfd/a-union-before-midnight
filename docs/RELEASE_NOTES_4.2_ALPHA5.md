# A Union Before Midnight 4.2.0-alpha.5

Alpha 5 is an emergency government-system rollback. It retains the Alpha 4
manpower, formation, procurement, Himalayan, upgrade and Steam Deck work.

## Government rollback

- Restores `ministers_ind.csv` byte-for-byte from the last known-good Alpha 3
  package, including Jawaharlal Nehru and the established replacement pool.
- Restores the Alpha 3 constitutional mandate event exactly.
- Removes the triennial national mandate experiment, event 9270104.
- Removes the automatic minister-register migration, event 9270784, including
  all `sleepminister` commands.
- Does not alter existing save files. Saves made before the broken migration
  can be resumed directly after restarting Darkest Hour.

The government system will remain frozen at the known-good implementation
until it can be redesigned against a disposable save and verified in game.
