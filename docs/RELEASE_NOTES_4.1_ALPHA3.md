# A Union Before Midnight 4.1.0-alpha.3

## Campaign continuity

- Replaced critical China, Siam, Pacific and coalition reactions with triggers based on the live diplomatic and military state.
- Extended recoverable India event windows through 1964. Missing an earlier date no longer permanently kills a valid narrative chain.
- Added permanent Allied, German, Soviet, Japanese and independent war-entry decisions. They remain available after an earlier refusal and while India is fighting a separate war.
- Added a save-compatible strategic-ledger reconciliation event and synchronized both V3 and V4 strategy flags on every later alignment choice.
- Added direct-DH Japanese AI policy entries for sovereign India wherever stock files address the British Raj tag.

## Armed forces and research

- Removed fixed event production costs, partial-completion grants and forced model resets. Event orders now use India's researched model at the engine's normal cost and build time.
- Limited event air orders to one wing per line to prevent cheap serial expansion.
- Converted major fleet grants to named, normal production orders. Standing, elite, mobilized and transferred formations deploy once at the currently researched model and partial strength, preserving reinforcement costs without creating an extendable queue exploit.
- Guaranteed core research institutions by 1935, advanced service schools by 1938, aeronautics by 1940 and atomic research by 1944. Earlier choices still provide a head start.
- Expanded the usable officer list and removed destructive random leader purges.

## Government and compatibility

- Made constitutional cabinet watchdogs persistent through 1964.
- Added a visible Gandhi-Nehru cabinet restoration decision when their mandate is active but slider changes replace either office.
- Preserved compatibility with existing V4 campaigns; the release includes no province ownership or scenario-tag migration.

## Release gates

- 365 India events validated with zero errors and zero warnings.
- 139 event production orders validated as research-owned and normal-cost, plus 83 one-off current-model partial-strength deployments.
- Construction safety, infrastructure caps, event art, personnel art, service sprites, opening economy and combat pacing all pass their automated release gates.
