# Current-state decisions and shared withdrawal review

10 September 2026. Staged scripts only. **Not installed, not a playable release,
and not tested in the native game.** The existing installation and save are
protected inputs. The player intends a new campaign.

Subsequent extension: [Bhutan now shares Nepal's merger/integration lifecycle](HIMALAYAN_MERGERS.md).
The Stage5 counts below describe the preceding build; the current manifest is
`EVENT-REDESIGN-STAGE5-HIMALAYA` and includes seven additional Bhutan callbacks/decisions.

## Less navigation, without deleting the rewards

One **Diplomacy and Campaigns** gateway replaces the old route-board portal.
It opens treaties, possible opponents, campaign results, and Japanese joint
operations only when India actually has the appropriate alliance or compact.
Opening these pages does not declare war or make a commitment. Campaign results
remain accessible after peace, not just while India is fighting.

Fourteen redundant navigation/recording pages become harmless close pages; their
IDs remain defined for compatibility. Back links no longer queue another popup.
Thirty-five secondary-ledger mirror writes are removed only after checking that
no loaded condition reads them. Real rewards, declarations and commitments are
not removed with the menus. Tests check graph reachability to the former boards'
substantive destinations; native visibility and delivery still need testing.

This is not removal of every ledger or global route gate. Japanese chapter
milestones and the paid Caucasus relief transaction retain substantive legacy
requirements pending their own lifecycle review.

## Replies belong to their actual offer

The Japanese seniority review and the Persian, Afghan and Xinjiang corridor
families now check current relationships and track the selected response locally.
A stale reply cannot simply consume the current Indian notice. Retry timers own
their cooldown rather than clearing a newly dispatched offer. Repeated limited
corridor deals cannot stack the permanent transport/intelligence bonus.

Original prices, response odds and delays remain. Japanese deferral remains
retryable; explicit rejection retains the original permanent restriction.
Independent anti-Soviet campaigning is still supported: a corridor request does
not invent a requirement to join Germany. Disappearing recipients and generation
identity across repeated identical offers are not fully solved by these tokens.

## Opportunities follow the battlefield

Fourteen events in the wartime settlement module no longer require the global
sovereign route or the manual Liberator activation flag. Their real conditions,
costs, timers and rewards remain:

- **Defend Suez:** being Britain's ally no longer disqualifies India. Actual Axis
  hostility, friendly canal control and the Indian garrison are still required.
- **Tibetan investment:** actual Indian puppetry and the required territorial
  situation determine access, not India's unrelated great-power alignment.
- **Persian–Afghan corridor:** the relevant Indian-held or Indian-protected
  territory counts without requiring the sovereign political route.
- **Replacement training:** the existing annual wartime class still requires
  war with Japan or the USSR, the army/manpower thresholds and its resource bill.

These edits do not increase the rewards or make the territorial holds easier.

## Shared minor exits

The staged withdrawal work covers Siam, Nanjing and Indochina as one registered
family. Detachment executes in the minor's country, not as an Indian peace with
Japan. Government and settlement rewards require verification; there is no
compensating declaration of war to hide an unintended peace.

Three existing installed-only verification IDs, 9297200–9297202, are explicitly
ported rather than treated as unregistered additions. Eight alternate generic
peace entry points for these minors also receive action-level sovereignty and
alliance checks. This does not certify all other countries' peace chains.

The old all-country war comparisons are no longer repeated inside enormous
action conditions. Short conditional commands check the recorded wars before
government/reward commands. If that check fails, only this settlement attempt's
provenance is cleared, preventing a repeating no-effect notice. This depends on
the engine evaluating conditional commands in sequence; the static tests model
that order, but cannot establish that the engine uses it.

Native coalition war-list changes, command ordering, puppet creation and queued
delivery remain release blockers. Script verification is not evidence that the
engine will preserve India's wars. Large generated effect tooltips also require
native inspection; shortening an action predicate alone cannot prove readability.

Measured limitation: the shared unit's largest action condition is now 2,029
characters, but one Nanjing withdrawal still contains 1,029 commands and about
100 KB of command text. The verification callbacks contain roughly 350 commands
each. Most are snapshot/check bookkeeping, but that does **not** make them
invisible to the UI. This is an explicit effect-tooltip release blocker, not a
finished solution to the player's clutter complaint.

## Verification and release status

The generated `build/redesign/manifest.json`, `reviews.json`, `coverage.json` and
`presentation-audit.json` record the integrated result and exact scope. Partial
dimension reviews do not mark an event's whole lifecycle complete.

The Stage5 build preserves all **5,553 original IDs**, with **516 existing
blocks changed cumulatively** and 16 additions: six stories, seven Nepal
follow-ups and the three ported safety callbacks. There are 5,569 staged custom
events and 543 events with some recorded dimension work. No event is represented
as fully lifecycle-reviewed or engine-tested. All protected input hashes remain
unchanged. The presentation audit has no hard budget/control-code errors, but
1,353 conservative layout candidates remain; these are not 1,353 confirmed
broken popups. `installable` remains `false`.

The final integrated regression run passed **214 tests**. Independent review
caught and corrected failed-audit watcher repetition, stale regional ratification
after peace, and a misleading final corridor title. Tests cover scripts and
modeled state transitions, not native engine execution or rendered UI.

Remaining work includes the rest of the installed safety overlay, stock Japanese
settlement interactions, other route-gated rewards, hold-timer behavior, the
large Japanese-aggression observer predicates, further prose/economic families,
and an isolated fresh-1933 native test. The six earlier small flavour stories
are unchanged; this pass prioritizes functional repairs rather than claiming
they provide the fuller new experience requested.
